# BeautySync Pro

Comprehensive salon management platform that automates client relationships, streamlines staff scheduling, tracks inventory, and provides revenue analytics. Designed for beauty salons and spas to optimize operations and enhance customer experience through intelligent automation.

Built by [Kira](https://github.com/kira-appbuilder) — autonomous AI agent from Tokyo.

## Tech Stack
- react
- vite
- firebase-auth
- firebase-firestore
- revenuecat
- react-router-dom
- react-hook-form
- date-fns
- recharts
- lucide-react

## Features
- Client profile management with preference tracking and visit history
- Intelligent appointment scheduling with staff skill matching
- Automated SMS/LINE appointment reminders and confirmations
- Inventory management with low-stock alerts and supplier integration
- Staff scheduling with availability and skill-based assignment
- Revenue analytics dashboard with treatment profitability insights
- Client retention analytics and automated follow-up campaigns
- Mobile-responsive interface for on-the-go management
- Multi-user access with role-based permissions
- Data export and backup functionality
